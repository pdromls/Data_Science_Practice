# Data Science & Machine Learning Practice 🚀

Repositório dedicado ao acompanhamento prático, aprofundamento teórico e implementação de projetos ao longo do curso de Data Science e Machine Learning.

O diferencial deste repositório é a **abordagem crítica**: além de reproduzir os exercícios e técnicas ensinadas, os notebooks trazem comparações metodológicas, questionamentos sobre certas decisões técnicas e implementações de melhores práticas de mercado.

---

## 🗺️ Trilha de Estudos & Roadmap

O repositório é atualizado de forma contínua conforme avanço pelos módulos do curso:

### 1. Preparação e Análise de Dados *(Em andamento)*
- [x] Configuração do ambiente e boas práticas de versionamento
- [ ] Análise Exploratória de Dados (EDA - *Exploratory Data Analysis*)
- [ ] Limpeza, tratamento de nulos e outliers (*Data Cleaning & Wrangling*)
- [ ] Engenharia de Atributos (*Feature Engineering*): transformações, escalonamento e encoding de variáveis categóricas

### 2. Fundamentos de Machine Learning
- [ ] Introdução aos conceitos e tipos de aprendizado (supervisionado, não-supervisionado)
- [ ] Métricas de avaliação, validação cruzada (*Cross-Validation*) e divisão de dados (Train/Validation/Test)
- [ ] Diagnóstico de modelos (*Bias-Variance Tradeoff*, *Overfitting* vs. *Underfitting*)

### 3. Modelos de Regressão & Regularização
- [ ] Regressão Linear: intuição matemática, suposições teóricas e implementação prática
- [ ] Técnicas de regularização: Ridge (L2), Lasso (L1) e Elastic Net
- [ ] Otimização e ajuste de hiperparâmetros

### 4. Ciclo de Vida Real de um Projeto de ML (*End-to-End ML Lifecycle*)
- [ ] Da definição do problema de negócio ao pipeline de pré-processamento
- [ ] Estruturação de código modular, reprodutibilidade e boas práticas de engenharia
- [ ] Considerações sobre deploy, monitoramento e manutenção de modelos

### 5. Algoritmos Clássicos e Avançados de Classificação & ML
- [ ] Regressão Logística (*Logistic Regression*)
- [ ] Máquinas de Vetores de Suporte (*Support Vector Machines - SVM*)
- [ ] Teorema de Bayes e Naive Bayes
- [ ] K-Nearest Neighbors (*KNN*)
- [ ] Árvores de Decisão, Random Forest e Métodos de Ensemble (*próximos passos*)

---

## 💡 Estrutura dos Notebooks

Cada notebook/estudo é organizado para conter:
- **Contexto e Objetivos:** o problema que está sendo resolvido.
- **Passo a Passo Prático:** execução do código e transformações de dados.
- **Notas Críticas & Alternativas:** considerações analíticas, discordâncias fundamentadas em relação a abordagens simplificadas das aulas e testes com abordagens alternativas.
